# Canadian Coin Collection

Open index.html after extracting the entire folder, or publish its contents to GitHub Pages. No build step or image hotlinking is needed.

The original 182 records and 81 owned defaults are unchanged. Existing selections use the same localStorage key, `alex-coins-v1`; storage belongs to the current browser and site origin. Opening a local ZIP does not transfer selections from GitHub Pages.

164 locally bundled photographs can be enlarged by mouse or keyboard. Close with Escape, the Close button, or a click outside the image dialog. Missing coins retain their original colours to distinguish variants. The remaining 18 records have source links instead of incorrect or unlicensed photographs. All records retain independent collection controls.

## Image sources and usage

Photos © CNumis (including its Coin des Monnaies branding). Original files and watermarks are preserved. Each card links to its catalog source; `image-sources.json` records the mapping, original image URL and file checksum.

CNumis permits personal, informational and educational use, requests attribution for noncommercial use, and reserves the right to refuse use in rare cases. Images explicitly credited to outside suppliers, including Heritage Auctions, were excluded. Source: https://cnumis.com/en/catalog/global-images/canada-16 (checked 2026-10-07).

Royal Canadian Mint terms permit one personal noncommercial copy with notices intact, while prohibiting distribution and other reproduction without written consent. Its IP policy includes an application process for online coin imagery. Therefore Mint images are not copied or hotlinked in this publicly deployable package; Mint reference links are used where appropriate. Attribution alone does not grant Mint redistribution rights.

## Exact-variant gaps

Source links are used for IDs 0, 2, 70, 71, 73, 80, 82, 88, 110, 130, 132, 158, 160, 174, 175, 177, 179 and 181. Available photos were missing, showed another year, or showed a colour version of a noncolour entry. No colours were digitally removed to manufacture a variant. ID 110 (2005 Lucky Loonie) is retained exactly as originally supplied, but the linked catalog dates the identified design to 2006; it needs verification. Catalogue links can change over time; local photos continue working offline.
