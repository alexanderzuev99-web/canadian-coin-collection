# Canadian Coin Collection

Personal checklist of Canadian special and commemorative circulation coins. Open `index.html` with the bundled files or use GitHub Pages; no build step is needed.

## Collection and saved progress

The checklist contains 175 entries and 81 owned defaults. Seven silver-composition circulation issues were removed: the 1967 mackerel dime, 1967 bobcat quarter, and the 1939, 1949, 1958, 1964 and 1967 commemorative dollars. Nickel commemorative dollars from 1970–1984 remain. Composition references: [10 cents](https://www.mint.ca/en/discover/canadian-circulation/10-cents), [25 cents](https://www.mint.ca/en/discover/canadian-circulation/25-cents), [1 dollar](https://www.mint.ca/en/discover/canadian-circulation/1-dollar).

Existing coin IDs and the `alex-coins-v1` localStorage key remain unchanged. Saved owned selections override the defaults on the same browser and site origin. Removed IDs are ignored; remaining entries are never renumbered. Search, denomination filters, Missing only, progress and photo enlargement remain available.

## Photographs

169 entries have bundled images of the listed variant. Twelve images were replaced with verified exact variants: Sir Isaac Brock (non-colour), Alexander Graham Bell (non-colour), Oscar Peterson (non-colour), Bill Reid (both variants), Unknown Soldier (both variants), Daphne Odjig (non-colour), CN Tower (both variants), and Royal Canadian Legion (both variants). Unknown Soldier now shows the individual coin instead of a coin-and-roll image.

Six entries use source links while an exact photograph is pending: IDs 70, 71, 73, 82, 110 and 158. Colour photographs are not displayed as non-colour variants. The original 2005 Lucky Loonie entry (ID 110) remains pending date verification.

Photos are credited to CNumis, Wikimedia Commons contributors, Royal Canadian Mint and Imaginaire. Original imagery and any embedded notices are preserved. Mint and Imaginaire imagery is included at the owner's request for this personal noncommercial checklist. `image-sources.json` and `images.js` record matching local paths, source pages, original image URLs and SHA-256 checksums. Source attribution does not imply ownership of the photographs. Older unused bundled files are retained for recovery.
